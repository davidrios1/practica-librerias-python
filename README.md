# Proyecto Python - Análisis de Ventas

## Descripción del proyecto

Este proyecto fue desarrollado como parte de una actividad académica para aprender a crear entornos virtuales en Python, instalar librerías y utilizarlas mediante código.

El proyecto consiste en analizar las ventas de una tienda de relojes y accesorios, utilizando datos simulados para calcular los ingresos y generar una gráfica comparativa.

## Librerías utilizadas

### 1. NumPy
Permite realizar cálculos matemáticos y trabajar con arreglos numéricos. Se utiliza para calcular los ingresos de cada producto y el total vendido.

### 2. Matplotlib
Permite crear y personalizar gráficas. En este proyecto se utiliza para configurar y guardar la gráfica de ventas.

### 3. Pandas
Permite organizar, manipular y analizar datos mediante tablas. Se utiliza para presentar la información de los productos
